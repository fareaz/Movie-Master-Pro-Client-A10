 🚀 **About the Project**

**MovieMaster Pro** is a dynamic movie management platform that allows users to explore, upload, and manage their favorite movies with ease.  
It acts like a personal movie library — users can browse, upload, and create their own watchlists inside a sleek, modern interface.

---

## ✨ **Key Features**

- 🎥 **Personal Movie Library:** Upload, edit, and delete your own movies.  
- ❤️ **Watchlist Management:** Add movies to your watchlist or remove them anytime.  
- 🔒 **User Authentication:** Only logged-in users can upload, edit, or view personal pages.  
- 🏆 **Top Rated & Recently Added:** Automatically displays the top 5 rated and latest added movies.  
- 📊 **Platform Statistics:** Shows total movies and total users in real-time.  
- 🔍 **Advanced Filtering:** Filter movies by **genre**, **rating range**, or **search keyword**.  
- 🎭 **Explore by Genre:** Dynamically view movies by genre with smooth animations.  
- 💡 **Responsive Design + Dark Mode:** Works beautifully on all devices with theme toggle and hamburger menu.  
- 🧱 **Protected API Routes:** Backend routes secured with Firebase authentication.
